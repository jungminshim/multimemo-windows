# 멀티 메모 (Windows)

한 화면에 여러 개의 스티커 메모를 동시에 띄우는 프로그램입니다.
메모 개수에 맞춰 화면이 자동으로 나뉘고, 각 메모는 따로따로 `.txt` 파일로 저장됩니다.

## 실행

1. [Python](https://www.python.org/downloads/windows/) 설치 (tkinter 포함 기본 설치)
2. `멀티메모 실행.bat` 더블클릭

## 사용

| 기능 | 방법 |
|---|---|
| 새 메모 | Ctrl+N 또는 ＋ 버튼 |
| 색 바꾸기 / 삭제 | ● / ✕ 버튼 (삭제 시 `notes\_삭제됨`으로 이동) |
| 글자 크기 5~20pt | 툴바 －/＋ 또는 Ctrl + 마우스 휠 |
| 굵기 | 툴바 얇게 / 보통 / 굵게 |
| 새 탭 (엑셀 시트처럼 메모판 추가) | 아래 탭 줄 ＋ 또는 Ctrl+T |
| 탭 이동 | 탭 클릭 또는 Ctrl+Tab |
| 탭 이름 바꾸기 | 탭 더블클릭 |
| 탭 순서 이동 / 삭제 | 탭 우클릭 |
| 탭 저장 / 불러오기 | 툴바 '탭 저장'(.zip) / '탭 불러오기' |
| 글자 서식 | 글자를 드래그하면 뜨는 서식 바: 굵게(Ctrl+B) / 기울임(Ctrl+I) / 취소선(Ctrl+Shift+X) / 형광펜(Ctrl+Shift+H) / 지우기 |
| 체크리스트 | 메모 위 ☑ 버튼 또는 Ctrl+L → ☐ 클릭하면 ☑ + 취소선, 엔터로 다음 항목 |

메모는 `notes\<탭 이름>\` 폴더에 메모별 `.txt` 파일로 자동 저장됩니다.
탭 저장 .zip 파일은 맥·아이폰 버전과 서로 주고받을 수 있습니다.

- 맥 버전: https://github.com/jungminshim/multimemo-mac
- 아이폰/웹 버전: https://jungminshim.github.io/multimemo/
